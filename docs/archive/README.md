- **`implementation-plans/`** - Implementation plans and summaries from past releases
  - `IMPLEMENTATION_PLAN_v0.7.0.md` - Plan for v0.7.0 (Observability)
  - `IMPLEMENTATION_SUMMARY_v0.7.0.md` - Summary for v0.7.0
  - `IMPLEMENTATION_PLAN_v0.7.1.md` - Plan for v0.7.1
  - `IMPLEMENTATION_SUMMARY_v0.7.1.md` - Summary for v0.7.1

- **`blog-posts/`** - Blog posts and articles
  - `review.md` - Habr article draft for v0.5.0

## Purpose

These files are kept for historical reference and to understand the evolution of the project. They are not actively maintained but may be useful for:
- Understanding design decisions
- Reviewing implementation approaches
- Historical context for features
